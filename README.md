# 월계는 처음이라

**월계1동에 처음 온 사람에게, 내 상황에 해당하는 할 일만 기한과 함께 알려주는 웹앱.**
막히면 묻고, 먼저 와 본 주민의 답이 확인을 거쳐 다음 사람의 할 일이 됩니다.

**🔗 서비스 바로가기 — https://nowonlikeus.vercel.app**

2026 KW 해커톤 (광운대학교) · **배리어프리 및 생활 편의** 트랙 · 13조 NowonLikeUs

---

## 30초 요약

- **문제** — 광운대가 있는 월계1동은 2~4년마다 사람이 바뀝니다. 쓰레기 배출 요일, 전입신고 기한 같은 생활 지식이 사람과 함께 매년 사라지고, 새로 온 사람은 **무엇을 모르는지조차 모릅니다.**
- **해결** — 집 형태 · 계약 형태만 넣으면 **나에게 해당하는 할 일만** 기한순으로 보여줍니다. 목록에 없는 건 질문하고, 주민이 답하고, 운영자가 확인하면 **다음 사람의 목록에 추가**됩니다.
- **믿을 수 있게** — 모든 정보는 팀이 공식 자료와 기관 전화로 **직접 확인**했고 출처가 붙어 있습니다. **AI는 정보를 만들지 않고** 확인된 카드를 고르기만 합니다.

## 풀려는 문제

**월계1동에서는 생활 지식이 매년 리셋됩니다.** 광운대 캠퍼스가 동 안에 있어 자취생 · 기숙사생이 2~4년 살다 떠나고, 그동안 쌓은 지식 — 쓰레기를 언제 어떻게 버리는지, 종량제 봉투를 어디서 파는지, 전입신고는 언제까지 하는지 — 도 함께 사라집니다.

**진짜 문제는 "모른다는 걸 모르는 것"입니다.** 검색은 질문을 알아야 할 수 있습니다. 전입신고를 14일 안에 해야 한다는 걸 모르면 검색도 못 하고, 그 결과는 과태료로 돌아옵니다.

**2026년 9월 16일, 국민권익위원회가 같은 문제를 공식 인정했습니다.** 「전입자 생활정보 사전안내 강화 방안」을 행정안전부와 기초지방정부에 권고했고, 여기엔 생활폐기물 배출 정보까지 포함됩니다. 노원구도 이행 대상입니다.

```
   ┌──────────────────────────────────────────────┐
   │                                              │

   │                                              │

   │                                    ▲         │

[막히면 질문] ─► [확인된 카드로 답] ─► [모르면 주민 답변 · 맞아요]
                AI 는 고르기만
```

쓸수록 월계1동의 로컬 지식이 쌓이고, 처음 온 사람이 다음 해에는 답하는 사람이 됩니다.

## 주요 기능

| 누가 | 화면 | 하는 일 |
|---|---|---|
| **처음 온 사람** (로그인 없음) | `/` 표지 · `/setup` 상황 입력 | 집 형태 · 계약 형태 · 이사일 · 차 · 반려동물 · 학생 여부 입력. 상세 주소는 받지 않음 |
| | `/tasks` 내 할 일 | 해당하는 일만, **가장 급한 일과 남은 날수**를 맨 위에. 완료 체크 · 진행률 |
| | `/tasks/[id]` 상세 | 안 하면 어떻게 되나 · 언제까지 · 어떻게 · 어디서. **전화 걸기** · 신청 페이지 바로가기 |
| | `/ask` 질문 | 확인된 할 일 카드로 답하고 신뢰도 배지(확인됨 / 일부만 / 모름) 표시. 모르면 이웃의 질문으로 |
| **먼저 와 본 주민** (로그인) | `/questions` 이웃의 질문 | 답변 달기, 다른 사람 답에 "맞아요". 주민 답변은 "운영자 확인 전"으로 표시 |
| **운영자** | `/admin/promotions` 승격 | 맞아요 순 큐 → 공식 자료로 확인 → 출처와 함께 할 일로 발행 → 조건 맞는 다음 사람 목록에 즉시 노출 |

**개인화 축이 "시점"이 아니라 "상황"입니다.** 전세면 확정일자가 뜨고, 기숙사면 안 뜹니다. 차가 있으면 거주자 우선주차가 뜨고, 없으면 안 뜹니다. **해당 없는 항목은 아예 보이지 않습니다.**

| 지역 단위 | 전국 동일 | 전국 공통 | 비구조화 | **월계1동 단위** |

## 믿을 수 있게 만든 장치

행정 정보가 틀리면 사용자가 실제로 과태료를 냅니다. 그래서 정확성을 기능보다 앞에 뒀습니다.

**1. AI는 정보를 만들지 않습니다.** AI는 질문에 맞는 **할 일 카드를 고르기만** 하고 문장을 쓰지 않습니다. 화면의 안내 문장은 서버가 정한 고정 문구입니다. 처음에는 AI가 쓴 문장에서 숫자를 걸러내려 했지만, "열나흘" 같은 한글 수치는 놓치고 "이번" · "이사일"은 숫자로 잘못 잡아서 방식을 바꿨습니다.

**2. 금액 · 기한 · 장소는 DB 원문 그대로입니다.** AI를 거치지 않으니 숫자가 틀릴 수 없습니다.

**3. 받으러 오는 사람에겐 문턱이 없습니다.** 상황 입력 · 할 일 · 완료 체크 · 질문은 로그인 없이 합니다. 로그인은 남들이 믿고 쓰게 되는 행동(답변 · 맞아요)과 운영자 승격에만 걸립니다.

**4. 개인정보를 최소로 받습니다.** 상세 주소는 받지 않습니다. 상황 정보는 브라우저에만 저장하고, 질문과 함께 남기는 상황은 집 형태 · 계약 형태뿐입니다. 질문자 닉네임은 공개 목록에 나가지 않습니다.

| 오정보 방지 | 상태 |
|---|---|
| 지식에 없으면 "모름" — 추측하지 않음 | ✅ |
| AI가 고른 근거 id를 서버가 실제 카드와 대조, 없으면 신뢰도 강등 | ✅ |
| 금액 · 기한 · 장소는 DB 원문 카드로만 | ✅ |
| 승격은 운영자가 출처를 적고 "직접 확인" 체크해야만 발행. 확인 수는 순서일 뿐 조건 아님 | ✅ |
| 확인 6개월 지난 정보에 "오래된 정보일 수 있습니다" 표시 | ✅ |
| 사용자의 "바뀌었어요" 갱신 요청 · 잘못된 답변 신고 | 예정 |

AI가 꺼지거나 실패해도 앱은 멈추지 않습니다. 키워드 검색으로 넘어가고, 할 일 목록 · 상황 매칭 · 질문 등록은 AI 없이 동작합니다.

```
브라우저 ── 상황 정보 · 완료 체크 (localStorage, 서버에 저장 X)
   │
   ▼
Next.js (Vercel) ── /api/tasks/match  상황 → 해당 할 일
   │                /api/ask         후보 → Gemini(카드 선택) → 서버 근거 검증 → 원문 카드
   │                /api/questions · answers · confirm · admin/promote
   ▼
Neon Postgres ── 할 일(출처 · 확인일) · 질문 · 답변 · 맞아요 · 계정
```

## 개발 관리

- **PR 기반 개발** — `master`(배포) ← `dev` ← `이름/작업` 브랜치. 모든 변경은 PR과 리뷰 승인을 거쳐 머지
- **CI** — PR마다 lint · 타입 검사 · 테스트 · 빌드 자동 실행
- **테스트 505건** — 상태 · 판정이 걸린 순수 로직만 단위 테스트 (상황 매칭, 기한 계산, AI 근거 검증, 키워드 검색, 승격 검증, 로그인 검증 등). 화면은 실제 브라우저와 API로 확인
- **커밋 규칙** — `<타입>: <제목>` (`Feat` `Fix` `Docs` `Style` `Refactor` `Test` `Chore`), [CONTRIBUTING.md](CONTRIBUTING.md)

## 직접 실행하기

```bash
npm install
cp .env.local.example .env      # 아래 환경 변수 채우기
npx prisma migrate dev
npm run seed                     # 확인된 할 일 17건
npm run seed:admin               # 운영자 계정 (ADMIN_EMAIL · ADMIN_PASSWORD)
npm run dev
```

`http://localhost:3000` 접속.

| 환경 변수 | 설명 |
|---|---|
| `DATABASE_URL` | Neon Postgres 연결 문자열 |
| `SESSION_SECRET` | 로그인 쿠키 서명 키 (32자 이상) |
| `GEMINI_API_KEY` | Gemini API 키. **비워도 앱은 동작** — 키워드 검색으로 대체 |
| `GEMINI_MODEL` | 기본 `gemini-3.1-flash-lite` |
| `GEMINI_ALLOW_USER_INPUT` | `true` 일 때만 질문을 Gemini로 전송. 켜면 질문 화면에 전송 사실을 고지 |
| `ADMIN_EMAIL` · `ADMIN_PASSWORD` · `ADMIN_NICKNAME` | `npm run seed:admin` 이 운영자 계정을 만들 때만 사용 |

질문 API의 데이터 처리와 외부 전송 조건은 [질문 API 안내](docs/ask-api.md)에 있습니다.
