## 6. 대형폐기물 — 확인 완료

### 신고 방법

온라인:

1. 스마트클린 노원 접속
2. 대형폐기물 배출 신청
3. 품목 선택
4. 수수료 결제
5. 배출증 출력 또는 수기 작성
6. 배출 물품에 배출증 부착
7. 신고 시 입력한 장소에 배출

배출장소는 원칙적으로:

- 내 집 앞
- 내 건물 앞

온라인 이용이 어려운 경우
가까운 주민센터에서도 신청 가능.

### 수수료

대형폐기물 수수료는 하나의 고정 금액이 아니라
품목과 규격에 따라 다르다.

노원구청에서
'대형폐기물 수집·운반 수수료 품목별 부과기준'을 제공한다.

따라서 특정 금액을 하나로 시드에 넣지 않고
품목별 공식 기준을 확인하도록 안내하는 것이 적절함.

### 주의사항

신고한 품목과 실제 품목 또는 수수료가 다르면
수거되지 않을 수 있으며 수수료 조정 후 수거한다.

### 무료 직접 처리 방법

소량의 폐기물을 직접 운반할 수 있는 경우:

공릉동 폐기물집하장
- 주소: 공릉동 657-10
- 전화: 02-2116-4994

노원구 거주를 증명할 수 있는 신분증을 지참하고
일반 승용차로 소량의 폐기물을 직접 반입하면
수수료 없이 처리 가능.

운영:
- 평일 07:00~16:00
- 토요일 07:00~15:00
- 일요일·공휴일 휴무

다량 반입 및 영업용 차량은 불가.
방문 전 전화 확인 필요.

### 출처

- 노원구청
- 「대형생활폐기물 배출안내」
- 스마트클린 노원

## 8. 동물등록 — 대부분 확인 / 월계동 특정 대행기관 추가 확인 필요

### 등록대상

현행 동물보호법 시행령 기준:

- 주택 및 준주택에서 기르는 월령 2개월 이상인 개
- 주택·준주택 외 장소에서 반려 목적으로 기르는 월령 2개월 이상인 개

### 등록기한

동물 소유권을 취득한 날 또는
등록대상 월령이 된 날부터 30일 이내 등록.

주의:
이 30일은 '이사일 기준'이 아니므로
dueOffsetDays에 30을 넣으면 안 됨.

dueOffsetDays: null

로 처리하고 howTo에 원문을 적는 것이 맞음.

### 등록 장소

- 관할 시·군·구
- 지자체가 지정한 동물등록대행기관

국가동물보호정보시스템에서
동물등록 대행기관을 조회할 수 있음.

### 미등록 과태료

- 1차: 20만원
- 2차: 40만원
- 3차 이상: 60만원

### 조건

requiresPet: true

### 아직 확인하지 않은 내용

월계1동/월계동에서 현재 실제로 운영 중인
특정 동물등록 대행기관의 기관명·주소.

외부 자료에서 병원 후보는 확인됐으나
공식 국가동물보호정보시스템에서 개별적으로 대조하기 전까지
시드에 특정 병원명을 넣지 않는다.

### 출처

## 11. 아파트 관리사무소 관련 — 일부 항목 확인 완료

'아파트 관리사무소가 모든 행정업무를 대행한다'는
공통 규칙은 공식 자료에서 확인되지 않았다.

따라서 단지마다 다를 수 있는 업무를 일반화하지 않는다.

현재 공식적으로 확인 가능한 범위만 기록한다.

### 11-1. 아파트 음식물쓰레기

공동주택은:

#### 120L 전용수거용기 방식

- 단지 내 전용수거용기에 배출
- 관리사무소에 총 수수료 부과
- 관리사무소가 세대별로 일괄 균등 부과
- 120L 기준 12,000원

#### RFID 방식

- 세대별 RFID 종량기에 배출
- 세대가 실제 배출한 양만큼 관리사무소가 세대별로 부과
- kg당 130원

실제 방식과 배출장소는
해당 아파트 관리사무소에 확인해야 함.

조건:
housingTypes: ['APARTMENT']

### 11-2. 아파트 소형 폐가전

청소기·전기다리미·가습기·전기밥솥·오디오·프린터 등
소형 폐가전이 5개 미만인 경우:

- 관리사무소에 문의
- 단지 내 재활용 배출장소에 배출

아파트 자체 재활용 업체를 이용하는 단지는
구청 소형폐가전 수거를 신청해도 수거하지 않을 수 있음.

소형가전 5개 이상은
폐가전 무상방문수거 서비스 이용 가능.

전화:
1599-0903

### 결론

아파트 관리사무소 관련 공통 항목으로
현재 공식적으로 확인 가능한 것은:

- 음식물쓰레기 수수료 세대별 부과
- 소형 폐가전 5개 미만의 배출방법 문의·단지 내 재활용장 이용

그 외 전입신고, 대형폐기물 신고 등의 대행 여부를
