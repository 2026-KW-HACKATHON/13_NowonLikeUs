# 질문 API와 데이터 처리

## 기본 동작

`POST /api/ask`는 기존 `AskRequest` / `AskResponse` 형식을 사용한다.
`text`는 공백 제외 내용이 있어야 하며 입력 길이는 최대 1000자다.
선택 프로필이 있으면 주거형태·계약형태·이사일을 검증한다.
잘못된 입력은 400, DB 조회·저장 실패는 상세 정보 없이 503이다.

`GEMINI_ALLOW_USER_INPUT`을 정확히 `true`로 설정하지 않으면 키가 있어도
Google을 호출하지 않는다. 기본 결과는 `mode: FALLBACK`, `answer: null`,
`confidence: UNKNOWN`과 공개된 DB 항목의 키워드 검색 결과다.
검색 카드의 숫자·날짜는 원문 그대로 유지한다. 카드가 없으면 빈 배열이다.

## 데이터 흐름

| 정보                                             | 자체 서버 처리       | 자체 DB 저장          | Google 전송(명시 활성화 시만) |
| ------------------------------------------------ | -------------------- | --------------------- | ----------------------------- |
| 질문 본문                                        | 입력 검증·검색       | 저장                  | 전송                          |
| 주거형태·계약형태                                | 허용된 열거값만 수용 | 질문 상황으로 저장    | 고정 한글 라벨만 전송         |
| 이사일                                           | 카드 기한 계산       | 저장 안 함            | 전송 안 함                    |
| 구역·차량·반려동물·학생 여부 및 기타 프로필 필드 | 사용하지 않음        | 저장 안 함            | 전송 안 함                    |
| 공개 Task의 id·제목·이유·절차                    | 검색·근거 구성       | 기존 데이터           | 전송                          |
| AI 답변·근거                                     | 서버 검증            | 검증 통과 결과만 저장 | 생성 응답 수신                |

클라이언트가 전체 프로필을 보내면 자체 서버에는 도착하지만 허용 목록 외 필드는
다시 전달하거나 저장하지 않는다. 가능하면 프론트에서도 불필요한 필드를 보내지 않는다.
질문에 사용자가 직접 적은 개인정보를 자동으로 완전히 제거하는 기능은 없다.
요청 본문과 오류 상세를 애플리케이션 로그에 남기지 않는다. 호스팅 로그 정책은 별도 확인한다.

## AI 활성화 조건

2026-10-03 확인한 [Gemini API 추가 약관](https://ai.google.dev/gemini-api/terms)에 따르면
무료 서비스의 입력·응답은 Google 제품·머신러닝 기술 개선에 사용될 수 있으며 사람이 검토할 수 있다.
개인정보·민감정보·기밀정보는 무료 서비스에 보내지 말아야 한다.
활성 결제 계정에 연결된 프로젝트로 사용하는 Gemini API는 유료 서비스 조건을 적용받으며,
제품 개선에는 사용하지 않지만 안전 목적 등의 제한적 로그 보관은 가능하다.

따라서 무료 티어 공개 서비스에서는 `false`를 유지한다. 환경 변수는 요금제를 자동 감지하거나
약관 준수를 보증하지 않는다. 유료 프로젝트 확인, 저장·제공 고지, 필요한 동의 및 운영 정책,
질문 제출 인증·남용 방지 준비를 완료한 뒤 운영자가 활성화해야 한다.
현재는 기존 브리프대로 `askerId`를 채우지 않는다. 공개 배포 전 인증 담당자와 연결해야 한다.

## 답변 안전 검사

Gemini 응답에 Unicode 숫자(전각·원문자 포함)나 흔한 한글 수량 표현이 있으면
응답 전체를 폐기하고 키워드 폴백한다. `groundAnswer`도 동일 검사로 재차 차단한다.
근거가 없거나 UNKNOWN인 AI 답변은 `answer: null`, 저장할 근거도 빈 배열이다.
한글 수량 검사는 휴리스틱으로 오탐·누락이 가능하며 숫자 없는 주소나 잘못된 설명의
정확성을 보장하지 않는다. 모든 자연어 수치를 완전히 막는다고 홍보하면 안 된다.

## 검증 범위

라우트 테스트는 실제 Gemini 파서·근거 검증·검색·카드 변환을 연결하고 DB와 HTTP만 대체한다.
기본값의 외부 호출 0회, 허용 필드만 전송·저장, 수치 차단, UNKNOWN, API 오류·DB 오류를 검증한다.
실제 DB 저장과 공개 사용자 질문의 실제 Google 전송은 테스트하지 않는다.
