# 월계는 처음이라 — 9/28 중간발표 범위 Implementation Plan

> **읽는 법:** task 단위로 순서대로 실행한다. 각 단계는 체크박스(`- [ ]`)로 진행 상황을 표시한다. 역할별 담당 범위는 [team/README.md](../team/README.md) 참고.

**Goal:** 상황 입력 → 나에게만 해당하는 할 일 목록 → 상세(전화 걸기·완료 체크) → 질문하면 로컬 지식으로 AI가 답하고 근거를 검증해 배지로 표시하기까지, 9/28 중간발표에서 그 자체로 동작·시연 가능한 "받는 쪽" 절반을 만든다.

**Architecture:** Next.js(App Router, TypeScript) 단일 웹앱. Postgres(Neon)에 Prisma로 접근. **로그인 없음** — 사용자 프로필과 완료 체크는 브라우저 localStorage에만 저장하고, 할 일 필터링은 프로필을 API에 실어 보내 서버에서 수행한다. AI는 Gemini를 직접 호출하되 DB의 할 일 데이터만 근거로 쓰고, AI가 반환한 근거 id를 서버가 실제 id와 대조해 신뢰도를 강등한다. AI 호출이 실패하면 키워드 검색으로 폴백해 앱이 멈추지 않는다.

**Tech Stack:** Next.js 15 (App Router) · TypeScript · Prisma + PostgreSQL(Neon) · Gemini API(REST 직접 호출, 구조화 출력) · Vitest

## Global Constraints

- 패키지 매니저는 **npm**을 사용한다.
- DB는 **Neon Postgres**, ORM은 **Prisma**. 스키마 변경은 `npx prisma migrate dev`로 관리한다.
- **9/28 범위에는 로그인을 만들지 않는다.** 회원가입·로그인·인증 미들웨어·질문 답변·확인·승격 화면은 이번 계획 범위 밖이다(본선 계획에서 다룬다).
- **상세 주소(번지·건물명·호수)는 수집하지 않는다.** 수집 항목은 구역·거주형태·계약형태·이사일·차량 보유·반려동물·학생 여부가 전부다.
- **AI는 행정·생활 사실을 생성하지 않는다.** DB에 있는 할 일 데이터만 근거로 답하고, 근거가 없으면 `UNKNOWN`을 반환한다.
- **금액·기한·장소는 AI가 다시 쓰지 않는다.** AI 답변은 안내 문장만 담고, 구체적인 값은 DB 원문을 그대로 렌더한 할 일 카드로 붙인다.
- **확인되지 않은 시드 데이터는 넣지 않는다.** 추정값으로 채우지 않고 비워둔다.
- 모든 `Task`는 `sourceNote`(출처와 확인 경로)와 `verifiedAt`(확인 날짜)을 **반드시** 가진다. 없으면 시딩이 실패해야 한다.
- 신뢰도 값은 `GROUNDED` | `PARTIAL` | `UNKNOWN` 셋뿐이다.
- 테스트는 **Vitest**로 작성하고, **상태·판정이 걸린 순수 로직만** 단위 테스트한다: 프로필→할 일 매칭, D-day·신선도 계산, 근거 id 검증, 키워드 검색. UI·라우트 배선은 `npm run dev` 후 브라우저 수동 확인으로 검증한다.
- 커밋 메시지 형식은 `<타입>: <제목>`이고 타입은 **대문자**로 시작한다(`Feat` `Fix` `Docs` `Style` `Refactor` `Test` `Chore`). 제목은 50자 이내, 끝에 마침표를 붙이지 않고, 명령문·현재형으로 쓴다.
- **커밋 메시지와 PR 본문에 AI 작성자 표기(`Co-Authored-By` 등)를 절대 넣지 않는다.**
- 작업 브랜치는 `<이름>/<작업내용>`으로 만들고 `dev`로 PR한다. `master`·`dev`에 직접 push하지 않는다.
- `push`는 담당자 확인 후 수행한다.

## 설계안과의 의도적 차이 (4건)

설계안(`docs/설계안.md`)과 다음 네 곳이 다르다. 전부 9/28 범위에서 불가피하거나 더 안전한 쪽으로 정한 것이다.

1. **`Question.askerId`를 nullable로 둔다.** 설계 2.3은 필수(`String`)지만 9/28에는 로그인이 없어 작성자를 특정할 수 없다. 본선에서 로그인을 붙이면 채워진다.
2. **`Task.sourceNote`를 필수(`String`)로 둔다.** 설계 2.3은 optional(`String?`)이지만, 설계 9.4의 커밋 규칙("시드 데이터는 `sourceNote`·`verifiedAt` 없이 커밋하지 않는다")과 7.1의 원칙을 DB 레벨에서 강제하는 쪽이 낫다.
3. **전월세신고의 `dueOffsetDays`는 `null`로 둔다.** 이 신고의 기한은 **계약일로부터 30일**인데 모델의 `dueOffsetDays`는 **이사일** 기준이다. 이사일 기준으로 환산하면 틀린 날짜가 나오므로 기한 계산을 비우고 `howTo`에 원문을 적는다.
4. **스키마는 본선 모델(`User`·`Answer`·`Confirmation`)까지 한 번에 만든다.** 기능은 9/28 범위만 구현하되, 스키마를 두 번 마이그레이션하면 화면과 AI 파이프라인 담당이 두 번 멈춘다(설계 9.1).

```ts
export type HousingType = 'ONE_ROOM' | 'OFFICETEL' | 'DORM' | 'APARTMENT' | 'VILLA';
export type ContractType = 'MONTHLY' | 'JEONSE' | 'DORM_FEE' | 'OWNED';
export type TaskCategory = 'ADMIN' | 'WASTE' | 'HOUSING' | 'LIFE';
export type Confidence = 'GROUNDED' | 'PARTIAL' | 'UNKNOWN';

/** 사용자가 /setup에서 입력하는 상황. 상세 주소는 수집하지 않는다. */
export interface Profile {
  zone: string;
  housingType: HousingType;
  contractType: ContractType;
  /** 'YYYY-MM-DD' */
  moveInDate: string;
  hasCar: boolean;
  hasPet: boolean;
  isStudent: boolean;
}

/** 할 일이 누구에게 보이는지. 빈 배열과 false는 "조건 없음"을 뜻한다. */
export interface TaskConditions {
  housingTypes: HousingType[];
  contractTypes: ContractType[];
  requiresCar: boolean;
  requiresPet: boolean;
  studentOnly: boolean;
}

/**
 * API가 화면으로 내려보내는 할 일 한 건.
 * 클라이언트 컴포넌트가 route 파일에서 타입을 끌어오지 않도록 여기 둔다.
 */
export interface MatchedTask {
  id: string;
  title: string;
  why: string;
  howTo: string;
  category: string;
  linkUrl: string | null;
  placeName: string | null;
  placeAddress: string | null;
  placePhone: string | null;
  daysLeft: number | null;
  overdue: boolean;
  stale: boolean;
  /** ISO 8601 */
  verifiedAt: string;
}
```

- [ ] **Step 2: 실패하는 테스트 작성 — `tests/matching.test.ts`**

```ts
import { describe, it, expect } from 'vitest';
import { matchesProfile, filterByProfile } from '@/lib/matching';
import type { Profile, TaskConditions, ContractType } from '@/lib/types';

const jeonseOneRoom: Profile = {
  zone: 'A',
  housingType: 'ONE_ROOM',
  contractType: 'JEONSE',
  moveInDate: '2026-03-02',
  hasCar: false,
  hasPet: false,
  isStudent: true,
};

const noConditions: TaskConditions = {
  housingTypes: [],
  contractTypes: [],
  requiresCar: false,
  requiresPet: false,
  studentOnly: false,
};

describe('matchesProfile', () => {
  it('조건이 전부 비어 있으면 누구에게나 해당한다', () => {
    expect(matchesProfile(noConditions, jeonseOneRoom)).toBe(true);
  });

  it('거주형태가 목록에 있으면 해당한다', () => {
    expect(matchesProfile({ ...noConditions, housingTypes: ['ONE_ROOM', 'VILLA'] }, jeonseOneRoom)).toBe(true);
  });

  it('거주형태가 목록에 없으면 해당하지 않는다', () => {
    expect(matchesProfile({ ...noConditions, housingTypes: ['APARTMENT'] }, jeonseOneRoom)).toBe(false);
  });

  it('계약형태가 목록에 없으면 해당하지 않는다', () => {
    expect(matchesProfile({ ...noConditions, contractTypes: ['DORM_FEE'] }, jeonseOneRoom)).toBe(false);
  });

  it('차량이 필요한 항목은 차량 없는 사람에게 보이지 않는다', () => {
    expect(matchesProfile({ ...noConditions, requiresCar: true }, jeonseOneRoom)).toBe(false);
    expect(matchesProfile({ ...noConditions, requiresCar: true }, { ...jeonseOneRoom, hasCar: true })).toBe(true);
  });

  it('반려동물이 필요한 항목은 반려동물 없는 사람에게 보이지 않는다', () => {
    expect(matchesProfile({ ...noConditions, requiresPet: true }, jeonseOneRoom)).toBe(false);
  });

  it('학생 전용 항목은 비학생에게 보이지 않는다', () => {
```

```ts
import type { Profile, TaskConditions } from './types';

/**
 * 할 일의 노출 조건이 이 프로필에 해당하는지 판정한다.
 * 빈 배열과 false는 "조건 없음"이므로 전원에게 해당한다.
 * 조건이 하나라도 어긋나면 false다.
 */
export function matchesProfile(conditions: TaskConditions, profile: Profile): boolean {
  if (conditions.housingTypes.length > 0 && !conditions.housingTypes.includes(profile.housingType)) {
    return false;
  }
  if (conditions.contractTypes.length > 0 && !conditions.contractTypes.includes(profile.contractType)) {
    return false;
  }
  if (conditions.requiresCar && !profile.hasCar) return false;
  if (conditions.requiresPet && !profile.hasPet) return false;
  if (conditions.studentOnly && !profile.isStudent) return false;
  return true;
}

export function filterByProfile<T extends TaskConditions>(items: T[], profile: Profile): T[] {
  return items.filter((item) => matchesProfile(item, profile));
}
```

```ts
const MS_PER_DAY = 86400000;

/** 약 6개월. 이 일수를 넘긴 정보에는 "오래된 정보" 배지를 단다. */
export const STALE_AFTER_DAYS = 183;

/** 자정 기준으로 잘라 날짜만 비교한다. 같은 날 안에서는 시각이 결과를 바꾸지 않는다. */
function toUtcMidnight(d: Date): number {
  return Date.UTC(d.getUTCFullYear(), d.getUTCMonth(), d.getUTCDate());
}

/**
 * 이사일 + 오프셋으로 기한을 구해 오늘까지 며칠 남았는지 센다.
 * 오프셋이 null이면 기한이 없는 할 일이므로 null을 돌려준다.
 */
export function daysUntilDue(
  moveInDate: string,
  dueOffsetDays: number | null,
  today: Date,
): number | null {
  if (dueOffsetDays === null) return null;
  const moveIn = toUtcMidnight(new Date(`${moveInDate}T00:00:00Z`));
  const due = moveIn + dueOffsetDays * MS_PER_DAY;
  return Math.round((due - toUtcMidnight(today)) / MS_PER_DAY);
}

export function isOverdue(daysLeft: number | null): boolean {
  return daysLeft !== null && daysLeft < 0;
}

export function isStale(verifiedAt: Date, today: Date): boolean {
  return (toUtcMidnight(today) - toUtcMidnight(verifiedAt)) / MS_PER_DAY >= STALE_AFTER_DAYS;
}
```

```ts
import { prisma } from '@/lib/db';
import { filterByProfile } from '@/lib/matching';
import { daysUntilDue, isOverdue, isStale } from '@/lib/dday';
import type { Profile, MatchedTask } from '@/lib/types';

export async function POST(request: Request) {
  const { profile } = (await request.json()) as { profile: Profile };
  if (!profile?.moveInDate) {
    return Response.json({ error: '프로필이 필요합니다.' }, { status: 400 });
  }

  const rows = await prisma.task.findMany({ where: { isPublished: true } });
  const today = new Date();

  const matched: MatchedTask[] = filterByProfile(rows, profile).map((t) => {
    const daysLeft = daysUntilDue(profile.moveInDate, t.dueOffsetDays, today);
    return {
      id: t.id,
      title: t.title,
      why: t.why,
      howTo: t.howTo,
      category: t.category,
      linkUrl: t.linkUrl,
      placeName: t.placeName,
      placeAddress: t.placeAddress,
      placePhone: t.placePhone,
      daysLeft,
      overdue: isOverdue(daysLeft),
      stale: isStale(t.verifiedAt, today),
      verifiedAt: t.verifiedAt.toISOString(),
    };
  });

  // 기한이 임박한 것부터. 기한 없는 항목은 뒤로 보낸다.
  matched.sort((a, b) => {
    if (a.daysLeft === null && b.daysLeft === null) return 0;
    if (a.daysLeft === null) return 1;
    if (b.daysLeft === null) return -1;
    return a.daysLeft - b.daysLeft;
  });

  return Response.json({ tasks: matched });
}
```

```ts
const KEY = 'wolgye.done.v1';

export function loadDone(): string[] {
  try {
    const raw = localStorage.getItem(KEY);
    return raw ? (JSON.parse(raw) as string[]) : [];
  } catch {
    return [];
  }
}

export function toggleDone(id: string): string[] {
  const current = loadDone();
  const next = current.includes(id) ? current.filter((x) => x !== id) : [...current, id];
  try {
    localStorage.setItem(KEY, JSON.stringify(next));
  } catch {
    // 저장 실패는 무시한다. 화면 상태는 반영된다.
  }
  return next;
}

export function isDone(id: string, done: string[]): boolean {
  return done.includes(id);
}
```

```ts
import type { Confidence } from './types';

export interface GroundingResult {
  confidence: Confidence;
  validSourceIds: string[];
  droppedSourceIds: string[];
}

/**
 * AI가 반환한 근거 id를 실제 id 집합과 대조한다.
 * AI는 존재하지 않는 id를 지어내므로 이 대조 없이는 답변을 신뢰할 수 없다.
 *
 * - 근거가 하나도 실재하지 않으면 UNKNOWN
 * - 허구가 섞여 있으면 PARTIAL로 강등
 * - AI가 스스로 GROUNDED가 아니라고 했으면 올려주지 않는다
 */
export function verifyGrounding(
  claimed: string[],
  known: Set<string>,
  aiConfidence: Confidence,
): GroundingResult {
  const unique = [...new Set(claimed)];
  const valid = unique.filter((id) => known.has(id));
  const dropped = unique.filter((id) => !known.has(id));

  if (aiConfidence === 'UNKNOWN' || valid.length === 0) {
    return { confidence: 'UNKNOWN', validSourceIds: [], droppedSourceIds: dropped };
  }
  if (dropped.length > 0) {
    return { confidence: 'PARTIAL', validSourceIds: valid, droppedSourceIds: dropped };
  }
  return { confidence: aiConfidence, validSourceIds: valid, droppedSourceIds: [] };
}
```

```ts
interface Searchable {
  title: string;
  why: string;
  howTo: string;
}

/**
 * Gemini 호출이 실패했을 때 쓰는 폴백 검색이다.
 * 질문을 공백으로 쪼개 낱말이 몇 개 걸리는지로 점수를 매긴다.
 * 임베딩을 쓰지 않는 것은 설계상 의도다 — 항목이 100건 내외라 이걸로 충분하다.
 */
export function keywordSearch<T extends Searchable>(items: T[], query: string, limit = 3): T[] {
  const words = query.trim().split(/\s+/).filter((w) => w.length > 0);
  if (words.length === 0) return [];

  const scored = items
    .map((item) => {
      const haystack = `${item.title} ${item.why} ${item.howTo}`;
      const score = words.filter((w) => haystack.includes(w)).length;
      return { item, score };
    })
    .filter((s) => s.score > 0)
    .sort((a, b) => b.score - a.score);

  return scored.slice(0, limit).map((s) => s.item);
}
```

```ts
import type { Confidence } from './types';

export interface GeminiAnswer {
  answer: string;
  sourceIds: string[];
  confidence: Confidence;
}

const SYSTEM_RULES = `너는 월계1동 생활 안내 도우미다.

규칙:
1. 아래 <지식>에 있는 내용만으로 답한다.
2. <지식>에 없으면 confidence를 UNKNOWN으로 하고 answer에 "아직 확인되지 않은 내용입니다"라고만 쓴다. 추측하지 않는다.
3. 금액, 기한, 날짜, 전화번호, 주소는 answer에 절대 쓰지 않는다. 그 값들은 화면에서 원문 카드로 따로 보여준다.
   answer에는 "어떤 항목을 봐야 하는지"만 안내 문장으로 쓴다.
4. 근거로 쓴 항목의 id를 sourceIds에 그대로 넣는다. 지식에 없는 id를 만들지 않는다.
5. answer는 두 문장 이내로 쓴다.`;

const RESPONSE_SCHEMA = {
  type: 'object',
  properties: {
    answer: { type: 'string' },
    sourceIds: { type: 'array', items: { type: 'string' } },
    confidence: { type: 'string', enum: ['GROUNDED', 'PARTIAL', 'UNKNOWN'] },
  },
  required: ['answer', 'sourceIds', 'confidence'],
};

/**
 * 실패하면 null을 돌려준다. 호출자는 폴백 경로를 타야 한다.
 * AI는 증강이지 필수 경로가 아니다.
 */
export async function askGemini(
  question: string,
  knowledge: string,
  profileLine: string,
): Promise<GeminiAnswer | null> {
  const apiKey = process.env.GEMINI_API_KEY;
  const model = process.env.GEMINI_MODEL ?? 'gemini-2.5-flash';
  if (!apiKey) return null;

  const prompt = `${SYSTEM_RULES}

<지식>
${knowledge}
</지식>

[사용자 상황] ${profileLine}
[질문] ${question}`;

  try {
    const res = await fetch(
      `https://generativelanguage.googleapis.com/v1beta/models/${model}:generateContent`,
      {
        method: 'POST',
        headers: { 'Content-Type': 'application/json', 'x-goog-api-key': apiKey },
        body: JSON.stringify({
          contents: [{ parts: [{ text: prompt }] }],
          generationConfig: {
            responseMimeType: 'application/json',
            responseSchema: RESPONSE_SCHEMA,
            temperature: 0,
          },
        }),
        signal: AbortSignal.timeout(15000),
      },
    );

    if (!res.ok) return null;

    const data = await res.json();
    const text = data?.candidates?.[0]?.content?.parts?.[0]?.text;
    if (typeof text !== 'string') return null;

    const parsed = JSON.parse(text) as GeminiAnswer;
    if (typeof parsed.answer !== 'string' || !Array.isArray(parsed.sourceIds)) return null;

    return parsed;
  } catch {
    return null;
  }
}
```

```ts
import { prisma } from '@/lib/db';
import { askGemini } from '@/lib/gemini';
import { verifyGrounding } from '@/lib/grounding';
import { keywordSearch } from '@/lib/search';
import { daysUntilDue, isOverdue, isStale } from '@/lib/dday';
import type { Profile, MatchedTask } from '@/lib/types';

const HOUSING_LABEL: Record<string, string> = {
  ONE_ROOM: '원룸', OFFICETEL: '오피스텔', DORM: '기숙사', APARTMENT: '아파트', VILLA: '빌라',
};
const CONTRACT_LABEL: Record<string, string> = {
  MONTHLY: '월세', JEONSE: '전세', DORM_FEE: '기숙사비', OWNED: '자가',
};

export async function POST(request: Request) {
  const { text, profile } = (await request.json()) as { text: string; profile?: Profile };
  if (!text || text.trim() === '') {
    return Response.json({ error: '질문을 입력해 주세요.' }, { status: 400 });
  }

  const rows = await prisma.task.findMany({ where: { isPublished: true } });
  const today = new Date();

  const toMatched = (t: (typeof rows)[number]): MatchedTask => {
    const daysLeft = profile?.moveInDate
      ? daysUntilDue(profile.moveInDate, t.dueOffsetDays, today)
      : null;
    return {
      id: t.id, title: t.title, why: t.why, howTo: t.howTo, category: t.category,
      linkUrl: t.linkUrl, placeName: t.placeName, placeAddress: t.placeAddress,
      placePhone: t.placePhone, daysLeft, overdue: isOverdue(daysLeft),
      stale: isStale(t.verifiedAt, today), verifiedAt: t.verifiedAt.toISOString(),
    };
  };

  const knowledge = rows
    .map((t) => `task:${t.id} | ${t.title} | ${t.why} | ${t.howTo}`)
    .join('\n');
  const knownIds = new Set(rows.map((t) => `task:${t.id}`));

  const profileLine = profile
    ? `${HOUSING_LABEL[profile.housingType] ?? profile.housingType} · ${CONTRACT_LABEL[profile.contractType] ?? profile.contractType}`
    : '상황 정보 없음';

  const ai = await askGemini(text.trim(), knowledge, profileLine);

  // 폴백: AI가 죽어도 관련 항목은 보여준다.
  if (!ai) {
    const hits = keywordSearch(rows, text);
    const q = await prisma.question.create({
      data: {
        text: text.trim(),
        confidence: 'UNKNOWN',
        sourceIds: [],
        ctxHousingType: profile?.housingType,
        ctxContractType: profile?.contractType,
      },
    });
    return Response.json({
      mode: 'FALLBACK',
      answer: null,
      confidence: 'UNKNOWN',
      tasks: hits.map(toMatched),
      questionId: q.id,
    });
  }

  const grounding = verifyGrounding(ai.sourceIds, knownIds, ai.confidence);
  const cited = rows.filter((t) => grounding.validSourceIds.includes(`task:${t.id}`));

  const q = await prisma.question.create({
    data: {
      text: text.trim(),
      aiAnswer: ai.answer,
      sourceIds: grounding.validSourceIds,
      confidence: grounding.confidence,
      ctxHousingType: profile?.housingType,
      ctxContractType: profile?.contractType,
    },
  });

  return Response.json({
    mode: 'AI',
    answer: grounding.confidence === 'UNKNOWN' ? null : ai.answer,
    confidence: grounding.confidence,
    tasks: cited.map(toMatched),
    questionId: q.id,
  });
}
```

```tsx
'use client';

import { useState } from 'react';
import Link from 'next/link';
import TaskCard from '@/components/TaskCard';
import ConfidenceBadge from '@/components/ConfidenceBadge';
import { loadProfile } from '@/lib/profile';
import type { Confidence, MatchedTask } from '@/lib/types';

interface AskResult {
  mode: 'AI' | 'FALLBACK';
  answer: string | null;
  confidence: Confidence;
  tasks: MatchedTask[];
}

export default function AskPage() {
  const [text, setText] = useState('');
  const [loading, setLoading] = useState(false);
  const [result, setResult] = useState<AskResult | null>(null);

    e.preventDefault();
    if (!text.trim()) return;
    setLoading(true);

        headers: { 'Content-Type': 'application/json' },

    } finally {
      setLoading(false);
    }
  }

  return (
    <main>
      <h1>궁금한 걸 물어보세요</h1>

      <form onSubmit={handleSubmit}>
        <textarea
          value={text}
          onChange={(e) => setText(e.target.value)}
          placeholder="예: 쓰레기는 언제 버려요?"
          rows={3}
        />
        <button type="submit" disabled={loading}>
          {loading ? '찾고 있습니다…' : '물어보기'}
        </button>
      </form>

      {result && (
        <section>
          <ConfidenceBadge confidence={result.confidence} />

          {result.answer && <p>{result.answer}</p>}

            </p>
          )}

          {result.tasks.map((t) => (
            <TaskCard key={t.id} task={t} href={`/tasks/${t.id}`} />
          ))}
        </section>
      )}

      <Link href="/tasks">내 할 일로 돌아가기</Link>
    </main>
  );
```
